How This System Protects Hardware IP from Piracy

Stage 1: Watermark & Asymmetric Key Generation

The chip designer derives a unique watermark bitstream and creates an Asymmetric Keypair (Private Key PrK and Public Key PuK). The Private Key is kept secret by the designer, while the Public Key is stored in an open registry for future audits.

Stage 2: Watermark Embedding in Hardware Synthesis (HLS)

During circuit synthesis, a Conflict Interference Graph (CIG) is constructed. The watermark bits are embedded as artificial register conflict edges: bit 1 adds odd-odd variable constraints, while bit 0 adds even-even variable constraints. This embeds the watermark permanently into register allocation without changing circuit functional behavior.

Stage 3: Pedersen Commitment (C = G * h + r * H) & Timestamping

Before public release, the vendor computes a Pedersen Commitment:
C = (G * h + r * H) mod P
where h is the secret watermark integer and r is a random blinding factor. The vendor signs the design hash with their Private Key (PrK) and locks the registration timestamp.

Stage 4: Dispute Trial Verdicts (Genuine / Pirated / Modified)

When a suspect chip is audited, the server evaluates both proofs to render an easy verdict:
• GENUINE (Clean Design): Signature and commitment checks do not match vendor IP, indicating an independently designed core.
• PIRATED (Unauthorized Clone): The extracted watermark and signature match the genuine vendor's registered IP, confirming illegal duplication.
• MODIFIED (Tampered Circuit): Watermark or netlist logic was altered after signing, causing signature mismatch.
